The headline project

Profit Pilot

An event-driven quantitative trading platform. Thirty-nine locked modules on a deterministic, schema-validated event bus. An eight-governor risk spine that no signal can bypass. Six strategy sleeves competing for capital through an allocator. A research loop that proposes and tests its own parameter changes — behind an out-of-sample gate, a canary, a significance threshold and a cooldown. Running continuously in paper trading against a live brokerage API since mid-2026.

The credibility centerpiece

Research methodology

A Python validation pipeline for intraday futures research, built around one measurement. 60,480 parameter configurations were enumerated, scored on a training period, then run frozen on data the optimisation had never seen.

+0.087
Correlation between backtest performance and out-of-sample performance across all 60,480 configurations. The top 100 by backtest lost money out of sample 79% of the time — worse than picking at random from the same family. Everything downstream is designed around that fact.

Layer one · placebo

Shuffle the market, keep the volatility

Within-session bar permutation builds structure-free markets that preserve the volatility profile and destroy serial dependence. 300 worlds; the real result clears the null at p = 0.013 and 0.033 across two timeframes.

Layer two · bootstrap

Intervals, not point estimates

10,000 day-resamples per frozen config give confidence intervals on Sharpe and drawdown. One config in the committee returns P(Sharpe<0) = 0.502 — a coin flip, published as a null rather than dropped.

Layers three & four

Frozen out-of-sample, then audit every part

A sealed data vault with a pre-registered success criterion, still unopened. A component audit retired a deployed engine for adding points while cutting the book's Sharpe from 2.16 to 1.38.

Limitations
Every page carrying numbers has a limitations section — sample size, market era, fitting history, and what would have to be true for the result to be wrong. Not a footer disclaimer.
Negative results
A cross-symbol test that barely cleared costs, a component that added points but destroyed Sharpe, a confidence interval straddling zero — all still published.
Screenshots
Most console frames are captures of the live production system, with account balances and position values redacted. A few surfaces render the frontend's bundled sample dataset instead, and each of those is labelled demo mode in words next to the image.

The Python across these projects is AI-assisted. Architecture, event contracts, risk logic and choice of statistics are specified and reviewed by the author; the results are run and interpreted by the author.
