Calibration study output. Forward abnormal returns measured from the filing date, standard errors clustered by quarter, intervals bootstrapped over quarters.
The result is a null, published as one. Naive inference: 16 of 18 tests significant. Every 13F in a quarter is public within three days of the same deadline, so those events are not independent. Clustered by quarter: 2 remain, none surviving multiple-testing. Median t-statistic inflation 6×, worst case 67×.
Sources
Rate-limited EDGAR client. XML parsers for 13F-HR, Form 3/4/5 and Schedule 13D/G
CUSIP crosswalk
Built from the SEC's own fails-to-deliver files — covers 98% of position value with no licensed data
Data quality
Detects the 2023 change in 13F value units and the filers still ignoring it. Aggregates computed on a matched sample, so a filing-entity reorganisation is not published as a billion-share liquidation
Attribution
Every aggregate names its dominant filer, because one mis-keyed row moves a total by billions
Timing
13F is filed up to 45 days late. The tool prints the age of its own data and never presents it as real-time flow. Form 4 lands in two business days and is treated separately
Stack
Python 3.11+, SQLite, pandas / NumPy / SciPy. No paid data sources
Status
Working local tool with a CLI and a self-contained dashboard. No public deployment; repository pending approval to publish
Project two

Equity research agent

Ticker in, memo out. Every figure traceable to its filing, and a deterministic audit rejects the memo if it is not.

The citation audit, driven through ten failure modes. Each case is also an assertion in the test suite, so the demonstration cannot drift from the code.
The model never retrieves anything. No tools, no search. It gets one evidence book of ID-addressed datapoints and must cite the ID behind every figure. A deterministic audit then re-reads the memo and checks every number against what it cited — catching a plausible figure under a real source.
Saying "I don't know"
Provider failures become declared gaps with remedies rather than silent omissions. Nulls are never stored as placeholders. Data past its freshness policy is flagged. The memo carries a mandatory data-gaps section and a not_established field for claims the evidence cannot support
Reads the filings
Pulls the last two 10-K/10-Q documents and diffs Item 1A paragraph by paragraph. On the example run: 9 paragraphs added, 14 not restated, 3 materially reworded — including new disclosure on component supply and on securing compute capacity
Falsifiable artifacts
Ships the memo that passed, and the same memo with three figures altered and every citation untouched — the audit returns three errors while the untouched figures still pass
Found by its own tests
Treasury yields entered the evidence book as "0.0472%" because the provider reports decimal fractions. Exactly the silent, internally-consistent error the design exists to catch
Status
The evidence pipeline and citation audit run on public sources with no API key. The synthesis step calls the Claude API and has not been run end to end. Repository local only, pending approval
