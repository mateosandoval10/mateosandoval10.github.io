Rebuilds institutional and insider position flow from raw SEC filings, then tests whether any of it predicts returns. The calibration study was built to be able to fail, and it did.

Calibration study output. Forward abnormal returns measured from the filing date, standard errors clustered by quarter, intervals bootstrapped over quarters.
THE RESULT IS A NULL, AND IT IS PUBLISHED AS ONE. Under the naive assumption that events are independent, 16 of 18 tests look significant. Every 13F in a quarter becomes public within three days of the same deadline, so those events are not independent. Under inference clustered by quarter, 2 remain — and none survives a multiple-testing adjustment. Median t-statistic inflation from the naive method is 6×, and 67× in the worst case. The published answer is no detectable effect.
Sources
Rate-limited EDGAR client; XML parsers for 13F-HR, Form 3/4/5 and Schedule 13D/G. Quarter-over-quarter position deltas per filer, aggregated across filers per security
CUSIP crosswalk
Built from the SEC's own fails-to-deliver files — covers 98% of position value with no licensed data
Data-quality controls
Detects the 2023 change in 13F value units and the large filers still ignoring it three years later; collapses duplicate rows; keeps puts and bond principal out of share counts; computes aggregates on a matched sample of filers, so a filing-entity reorganisation is not published as a billion-share liquidation
Attribution
Every aggregate names its dominant filer, because one mis-keyed row moves a total by billions
Timing discipline
13F holdings are filed up to 45 days after quarter end. The tool states the age of the data in the output itself and never presents a 13F signal as real-time flow. Form 4 lands within two business days and is treated separately
Stack
Python 3.11+, SQLite, pandas / NumPy / SciPy. No paid data sources
Status
Working local tool with a CLI and a self-contained dashboard. No public deployment; repository pending approval to publish
Project two

Equity research agent

Ticker in, investment memo out — where every figure is traceable to its filing, and a deterministic audit rejects the memo if it is not.

The citation audit, driven through ten failure modes. Each case is also an assertion in the test suite, so the demonstration cannot drift from the code.
THE MODEL NEVER RETRIEVES ANYTHING. It has no tools and no search. It receives a fixed evidence book of ID-addressed datapoints, each carrying its source, URL and as-of date, and must cite the ID behind every figure it states. After generation a deterministic audit — plain Python, no model in the loop — re-reads the memo, extracts every numeric token and checks it against the datapoints actually cited. That catches the failure that matters: a plausible number attached to a real source.
Saying "I don't know"
Provider failures become declared gaps with remedies rather than silent omissions. Nulls are never stored as placeholders. Data past its freshness policy is flagged. The memo carries a mandatory data-gaps section and a not_established field for claims the evidence cannot support
Reads the filings
Pulls the last two 10-K/10-Q documents and diffs Item 1A paragraph by paragraph. On the example run: 9 paragraphs added, 14 not restated, 3 materially reworded — including new disclosure on component supply and on securing compute capacity
Falsifiable artifacts
The repository ships the memo that passed, the same memo with three figures altered and every citation left untouched (the audit returns three errors, one per altered figure, while untouched figures in the same sentences still pass), and a run against a foreign private issuer that returned 80 datapoints across 7 of 11 sections and declared 11 gaps with reasons
Found by its own tests
Four tests exist because of real bugs — including Treasury yields entering the evidence book as "0.0472%" because the provider reports decimal fractions. That is exactly the silent, internally-consistent error class the design exists to prevent
What it is not
No valuation modelling of its own — no DCF, no scenario analysis. Peer sets are supplied, not screened. Earnings surprises and estimate revisions sit behind a paid provider and are declared missing rather than approximated. Factor exposure stops at market beta. Coverage is US-centric. The audit checks grounding, not reasoning — a memo can pass every check and still reach a poor conclusion
Status
The evidence pipeline and citation audit run on public sources with no API key. The synthesis step calls the Claude API and has not been run end to end. Repository local only, pending approval

Why the footnote bug matters. A Form 4 is what an insider must file within two business days of trading their own company's stock. A scheduled Rule 10b5-1 sale, a tax withholding and a discretionary open-market sale are distinguished by exactly that footnote text — so misattributing it changes how a trade reads. The defect had been in shipped code since April 2025.

Each fix ships with regression tests that were verified to fail on the unpatched code and pass on the fix, so the tests demonstrably target the defect. The tractable issues on these projects already carry several competing unmerged pull requests each; reading the parser instead is why this work can be explained end to end.
