Project one

SEC EDGAR institutional-flow tracker

A rigorous, free alternative to the retail flow products, built on the SEC's own public filings rather than on a vendor's interpretation of them.

Sources
13F-HR quarterly institutional holdings · Form 4 insider transactions · 13D/G activist and >5% stakes, from the SEC EDGAR public API under its rate-limit and User-Agent policy
Computation
Position deltas quarter over quarter — new positions, exits, meaningful adds and trims, concentration changes — per filer and per security
Aggregation
Per-ticker flow view: who accumulated, who distributed, and how large the move was relative to that filer's own book and to the security's float
Timing discipline
13F data is filed up to 45 days after quarter end — lagged and backward-looking. The tool states this prominently and never presents a 13F signal as actionable real-time flow. Form 4 lands within two business days, so the two are treated as different instruments with different half-lives, and the tool explains why
Differentiator
Calibration. Where possible it measures whether these signals have any forward-looking value at all, and reports the answer even when the answer is "no measurable edge." A negative result with sound methodology is worth more than a dashboard implying an edge it has not demonstrated
Output
Structured CLI report plus a simple local dashboard
Status
In development. Repository scaffolded; no working end-to-end run yet, so no live link, no screenshot and no results claim on this page
Project two

AI equity research agent

Input a ticker, output a structured investment memo. OpenBB provides the data layer; an agent layer orchestrates retrieval, analysis and synthesis.

Memo structure

Requirement one
Every claim is traceable to its source — the filing, the datapoint, the date. A memo that cannot be audited is worthless to an institution
Requirement two
The agent must be able to say it doesn't know. Missing or stale data is handled explicitly rather than left for a language model to fill in. A hallucinated financial figure would be the single most damaging thing this portfolio could contain
Stack
Python · OpenBB data layer · Claude API reasoning layer
Status
In development. Repository scaffolded; no example memo published yet, because none has been generated end to end and verified
On empty states

Why this page looks like this

An unfinished project shown honestly is a smaller claim than a finished one, and a far smaller claim than a mock-up. It is also the only version of this page that survives someone clicking the link. The same rule governs the whole site: nothing here is a rendering of output that does not exist, and every empty state stays empty until there is something real to put in it.

What lands here when they ship
A report generated from live SEC filings, with the calibration result attached — including if it is null. And a complete example memo with its citations intact, generated end to end, not excerpted.
